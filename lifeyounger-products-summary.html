LiFe-Younger 全产品线工程摘要

来源：lifeyounger.cn

面向工程师的产品概览。已知数值已标注，其余为产品定位与技术形态说明。

一、充电系统（EV Charging Systems）

产品类型关键参数 / 技术形态
iTrailer 移动储能充电站 拖挂式储充一体 最大功率 180 kW，电池容量 217 kWh（首页另标注约 200 kWh）。兼具直流快充与应急电源双功能，可固定部署或随车移动。
iMChargerX 便携式直流快充 移动式 DC 快充设备，面向无固定电网场景。
iMChargerS 光伏直流快充 太阳能供电的 DC 充电方案，离网 / 补能场景。
iACharging 自动充电机器人 自动化对接充电，面向无人值守 / 自动泊车场景。
iCabinet 储充一体柜 储能 + 充电桩集成机柜，削峰填谷、扩容电网受限站点。
iMContainer 集装箱式充电站 标准集装箱化充电基础设施，大功率 / 多枪集群部署。

二、储能系统（Energy Storage Systems）

产品类型关键参数 / 技术形态
iMBase 移动储能系统 标准化机柜 标准化机柜设计，便于与拖车或车载系统无缝集成；支持多机并联扩容。
C&I ESS 工商业储能 企业级储能，峰谷套利、需量管理、备电。
Utility ESS 电网级储能 大规模电网侧储能，调频 / 调峰 / 新能源消纳。

工程视角要点

  • 核心技术栈：电芯化学体系未在首页公开，但产品命名（LiFe-Younger）及行业惯例指向 LiFePO₄（磷酸铁锂），强调安全性与循环寿命。
  • 产品架构思路：以模块化 / 标准化机柜为底座（iMBase），向上派生「移动储能（iTrailer）」与「储充一体（iCabinet）」，实现储能与充电的解耦复用。
  • 移动化是主线：iTrailer、iMChargerX、iMBase 等多款采用拖挂 / 便携设计，主打无需电网扩容、即放即用的应急与峰值补能场景。
  • 能源多元接入：iMChargerS 支持光伏直流直充，体现源-储-充一体的离网能力。
  • 场景覆盖：从单机便携（iMChargerX）→ 柜式（iCabinet）→ 集装箱（iMContainer）→ 电网级（Utility ESS），形成功率 / 容量梯度完整的产品矩阵。
⚠️ 参数缺口提醒：首页仅公开 iTrailer 的功率 / 容量，其余产品的电压等级、电池容量、充电枪标准（GB/T、CCS、CHAdeMO）、散热方式（风冷 / 液冷）、IP 防护、工作温度范围等均未披露。如需用于选型或方案设计，建议直接向厂商索取各产品 datasheet / 规格书。
